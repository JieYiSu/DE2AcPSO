# Contributing

Bug reports and reproducibility reports are welcome. Please include the
MATLAB release, PlatEMO release, operating system, experiment command, random
seed or run index, and the complete error message.

Keep algorithm changes separate from experiment or formatting changes. New
behavior should include a focused MATLAB unit test where practical. Do not
commit generated `Data` directories, large `.mat` archives, local paths,
temporary figures, or proprietary comparison implementations.
