# Included results

- `benchmark/`: descriptive statistics, Holm-adjusted comparisons, sign
  counts, and cross-instance Friedman/post hoc statistics.
- `ablation/`: Holm-adjusted comparisons for the three D=500 variants.
- `sensitivity/`: raw and summarized SOP F11 results for D=30 and D=500,
  together with the generated LaTeX table.
- `path_cost/`: run-completion records, the deterministic scene definition,
  and available generated figures.

Large per-run PlatEMO `.mat` archives are not included. See
`docs/DATA.md` for the raw-data release recommendation.
